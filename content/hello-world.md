Welcome to my blog. This site is **static HTML** — no JavaScript, no tracking,
no framework. Just markdown files compiled by a 150-line Python script.

## Why build it this way?

Because a blog post is just text, and text outlives platforms. This site will
still render in 30 years.

- Posts are plain `.md` files in a git repo
- The build step is a script I can read in one sitting
- Hosting is free (GitHub Pages / Netlify)

## Writing

I write in markdown, like everyone else:

> Simplicity is a feature.

Code blocks work too:

```python
print("hello, world")
```

And *emphasis*, **strong**, [links](https://example.com), the usual.
